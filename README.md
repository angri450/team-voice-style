# 团队说话风格设定

这个仓库放的是团队统一的 agent 说话风格设定。目的很简单：不管谁用什么工具跑 agent，写出来的东西都是同一个口吻。

## 仓库里有什么

| 文件 | 用途 |
| --- | --- |
| `团队说话风格-系统提示词-2026-11-13.md` | 提示词正文，整篇复制粘贴到 agent 的系统提示词位置 |
| `安装说明-2026-11-13.md` | 各工具的安装步骤、验证方法、团队维护约定 |
| `scripts/build_team_style.py` | 从 MiniMax Code 内置模板重新生成正文，模板更新后跑一次就能并入新条目 |

## 怎么用

打开安装说明，按里面的步骤贴一次，贴完按验证步骤确认生效。

想统一的是聊天和写作的口吻，工具本身的说明仍然由各自的产品维护，两边不冲突。

## 这份设定从哪里来

底稿是 MiniMax Code 自带的 agent 提示词模板，在每台装了桌面端的电脑上：

`C:\Users\Administrator\.minimax\agents\.builtin\mavis\agent.md`

它带 Handlebars 模板语法，不能直接分享，所以脚本把它展开、去掉跟终端界面和子任务相关的条件块，再把团队实际用出来的中文文风规则并进去。

中文文风规则来自 2026-11-12 整理的《我的语言偏好对齐》，那份文件记的是自我介绍和简历写作过程中反复返工换来的硬规则。

## 改了怎么办

1. 改 `scripts/build_team_style.py` 里对应的规则文本，或者改内置模板的引用方式。
2. 跑 `python scripts/build_team_style.py`，生成新的正文。
3. 对比一遍，改动确认没问题就提交，提交信息写清改了哪条规则。
4. 在群里说一声，提醒每个人更新。

文件名带日期，正文标题里也带日期，两处要一致。
